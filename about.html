PitStop is a location-first utility discovery app. It combines an instant starter dataset with live OpenStreetMap data so the interface stays responsive while the map gets richer.

Bathrooms 🚻

Where data exists, PitStop can distinguish public access, private access, unisex/all-gender or gender-specific information, accessibility, hours and fees. Businesses can appear too when they are mapped as having usable facilities. “Not specified” is used whenever a source does not provide a detail.

Parking P

Parking records can include free/paid status, capacity, access restrictions, opening hours and other mapped conditions. Pricing is never invented. If a source does not state the fee, PitStop says it is not specified.

EV charging ⚡

Charging records can include connector information, power/capacity, access, pricing and hours when those tags exist. Live charger availability is not guaranteed unless a connected live network provides it.

Fuel ⛽

Fuel stations can expose brand, fuel type, hours and price fields when mapped. Fuel prices change quickly, so users should confirm the displayed price before relying on it.
